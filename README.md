# 여행 수첩

일정 · 장소 메모 · 예약 · 쇼핑리스트 · 체크리스트를 한 앱에 모은 개인용 여행 앱(PWA)입니다.
기본으로는 **이 기기 브라우저(IndexedDB)** 에만 저장되고, Firebase를 연결하면 **친구를 초대해 여행을 같이 보고 고칠 수 있어요.**

---

## 1. Firebase 설정 (계정 · 같이 쓰기용 · 처음 한 번, 나만)

친구는 이 과정을 할 필요가 없어요.

1. <https://console.firebase.google.com> → **프로젝트 추가** (애널리틱스는 꺼도 됨)
2. **Authentication → 로그인 방법**에서 아래 두 개를 **사용 설정**
   - **Google**: 켜고, 프로젝트 지원 이메일에 내 메일 선택 → 저장
   - **이메일/비밀번호**: 첫 번째 스위치만 켜기 → 저장
   - (예전에 켠 '익명'은 꺼도 돼요)
3. **Authentication → 설정 → 승인된 도메인 → 도메인 추가**에 `<아이디>.github.io` 입력
   (이걸 안 하면 구글 로그인이 'unauthorized-domain' 오류로 막혀요)
4. **데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기**
   - Standard edition / ID는 `(default)` 그대로 / 위치 `asia-northeast3 (서울)` / **프로덕션 모드**
5. Firestore의 **규칙** 탭 → 내용을 전부 지우고 `firestore.rules` 를 통째로 붙여넣기 → **게시**
   (규칙 파일이 바뀌었을 때는 이 단계만 다시 하면 돼요)
6. **설정(톱니) → 프로젝트 설정 → 일반 → 내 앱 → `</>`** 로 웹 앱 등록 → 나오는 `firebaseConfig` 의 `{ ... }` 부분을
   `firebase-config.js` 의 `window.FIREBASE_CONFIG = ` 뒤에 붙여넣기

> 설정값은 원래 공개되는 값이라 깃헙에 올라가도 괜찮아요. 데이터는 규칙이 지켜요
> (내 여행은 나만, 공유한 여행은 초대받은 사람만).
> 무료 요금제(Spark)로 충분하고 결제 정보는 필요 없어요.

## 2. GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `tripnote` (Public)
2. 이 폴더의 파일을 **전부** 저장소 맨 위(루트)에 올립니다.
3. 저장소 **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `/(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/tripnote/` 로 접속합니다.

## 3. 앱 서랍(홈 화면)에 설치 · 로그인

- **안드로이드 Chrome**: 홈 화면의 '설치' 버튼, 또는 메뉴(⋮) → **앱 설치**
- **아이폰 Safari**: 공유 버튼 → **홈 화면에 추가**

홈 화면의 **로그인**을 누르고 구글 또는 이메일로 로그인하면 모든 여행이 계정에 저장돼요.
폰을 바꾸거나 앱을 지웠다 깔아도 **같은 계정으로 로그인하면 여행이 그대로 돌아와요.**
(아이폰 홈 화면 앱에서는 구글 로그인 창이 안 뜰 수 있어요. 그땐 이메일로 로그인하세요.)

한 번 열어두면 인터넷 없이도 열려요. 오프라인에서 고친 내용은 인터넷이 연결되면 계정과 친구에게 자동으로 반영돼요.

## 4. 친구랑 같이 쓰기

1. 같이 쓸 여행 → **설정 → 친구 초대하기** (로그인이 안 돼 있으면 로그인부터)
2. **카톡 등으로 보내기**(또는 초대 메시지 복사)로 링크를 보냄
3. 친구는 같은 주소에서 앱을 설치하고 **로그인**한 뒤, 링크를 열거나 앱 홈의 **초대 링크로 참여**에 받은 메시지를 붙여넣음
4. 이후 누가 고쳐도 서로 바로 반영돼요. 초대 안 한 여행은 내 폰에만 있어요.

- **아이폰**: 홈 화면 앱과 Safari는 저장 공간이 따로라서, 앱으로 쓰는 사람은 링크를 누르지 말고 **앱 안에서 '초대 링크로 참여'에 붙여넣기** 해야 해요. 카톡 안 브라우저로 열린 경우도 마찬가지예요.
- 만든 사람은 설정에서 **멤버 내보내기**, **초대 링크 새로 만들기**(예전 링크 무효)를 할 수 있어요.
- 초대받은 사람은 **공유에서 나가기**를 하면 지금까지 내용이 내 여행으로 사본이 남아요.
- 만든 사람이 여행을 삭제하면 모두에게서 사라져요.
- 같은 항목(예: 같은 장소)을 두 사람이 동시에 고치면 나중에 저장한 쪽이 남아요. 다른 항목끼리는 서로 덮어쓰지 않아요.

## 5. 데이터 옮기기

- **폰 바꿀 때**: 새 폰에서 같은 계정으로 로그인만 하면 끝이에요.
- **예전 Fukuoka Shopping 앱**: 같은 `<아이디>.github.io` 주소에서 쓰던 경우, 처음 열 때 '후쿠오카' 여행의 쇼핑 탭으로 자동으로 옮겨져요.
- **Claude에서 쓰던 여행 수첩**: 그쪽 앱에서 설정 → 백업 → **전체 복사** → 이 앱 홈에서 **백업 붙여넣기**
- **로그인 안 하고 쓸 때**: 여행마다 설정 → 백업 → **파일로 저장** → 새 폰에서 **백업 파일 불러오기**

## 6. 수정한 뒤 반영하기

`index.html` 등을 고쳐 올렸다면 `sw.js` 맨 위의 `VERSION`을 `tripnote-v3`처럼 올려 주세요.
설치된 앱을 한 번 껐다 켜면 새 버전이 적용돼요. (`firebase-config.js`는 VERSION을 안 올려도 최신으로 받아요.)
