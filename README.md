# 여행 수첩

일정 · 장소 메모 · 예약 · 쇼핑리스트 · 체크리스트를 한 앱에 모은 개인용 여행 앱(PWA)입니다.
기본으로는 **이 기기 브라우저(IndexedDB)** 에만 저장되고, Firebase를 연결하면 **친구를 초대해 여행을 같이 보고 고칠 수 있어요.**

---

## 1. Firebase 설정 (같이 쓰기용 · 처음 한 번, 나만)

친구는 이 과정을 할 필요가 없어요. 공유를 안 쓸 거면 건너뛰어도 됩니다.

1. <https://console.firebase.google.com> 에 구글 계정으로 들어가 **프로젝트 추가** → 이름 아무거나(예: `my-trip`) → Google 애널리틱스는 **끄고** 만들기
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기** → 로그인 방법에서 **익명** → 사용 설정 → 저장
3. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
4. Firestore 화면의 **규칙** 탭 → 원래 내용을 지우고 `firestore.rules` 파일 내용을 통째로 붙여넣기 → **게시**
5. 왼쪽 위 톱니바퀴 **프로젝트 설정 → 내 앱 → 웹(</>) 아이콘** → 앱 닉네임 입력 → 앱 등록
   (Firebase 호스팅 체크는 안 해도 돼요)
6. 화면에 나오는 `const firebaseConfig = { ... }` 의 **중괄호 부분**을 복사해서
   `firebase-config.js` 의 `window.FIREBASE_CONFIG = null;` 에서 `null` 자리에 붙여넣기

   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "my-trip-xxxx.firebaseapp.com",
     projectId: "my-trip-xxxx",
     storageBucket: "my-trip-xxxx.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```

> 이 설정값은 원래 공개되는 값이라 깃헙에 올라가도 괜찮아요. 데이터는 4번의 **규칙**이 지켜요
> (초대받은 사람만 그 여행을 읽고 쓸 수 있음).
> 무료 요금제(Spark)로 충분하고, 결제 정보를 넣을 필요 없어요.

## 2. GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `tripnote` (Public)
2. 이 폴더의 파일을 **전부** 저장소 맨 위(루트)에 올립니다.
3. 저장소 **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `/(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/tripnote/` 로 접속합니다.

## 3. 앱 서랍(홈 화면)에 설치

- **안드로이드 Chrome**: 홈 화면의 '설치' 버튼, 또는 메뉴(⋮) → **앱 설치**
- **아이폰 Safari**: 공유 버튼 → **홈 화면에 추가**

한 번 열어두면 인터넷 없이도 열려요. 오프라인에서 고친 내용은 인터넷이 연결되면 친구에게 자동으로 반영돼요.

## 4. 친구랑 같이 쓰기

1. 같이 쓸 여행 → **설정 → 친구 초대하기** → 내 이름 입력
2. **카톡 등으로 보내기**(또는 초대 메시지 복사)로 링크를 보냄
3. 친구는 같은 주소에서 앱을 설치하고, 링크를 열거나 앱 홈의 **초대 링크로 참여**에 받은 메시지를 붙여넣음
4. 이후 누가 고쳐도 서로 바로 반영돼요. 초대 안 한 여행은 내 폰에만 있어요.

- **아이폰**: 홈 화면 앱과 Safari는 저장 공간이 따로라서, 앱으로 쓰는 사람은 링크를 누르지 말고 **앱 안에서 '초대 링크로 참여'에 붙여넣기** 해야 해요. 카톡 안 브라우저로 열린 경우도 마찬가지예요.
- 만든 사람은 설정에서 **멤버 내보내기**, **초대 링크 새로 만들기**(예전 링크 무효)를 할 수 있어요.
- 초대받은 사람은 **공유에서 나가기**를 하면 내 폰에 사본만 남아요.
- 만든 사람이 여행을 삭제하면 모두에게서 사라져요.
- 같은 항목(예: 같은 장소)을 두 사람이 동시에 고치면 나중에 저장한 쪽이 남아요. 다른 항목끼리는 서로 덮어쓰지 않아요.

## 5. 데이터 옮기기

- **예전 Fukuoka Shopping 앱**: 같은 `<아이디>.github.io` 주소에서 쓰던 경우, 처음 열 때 '후쿠오카' 여행의 쇼핑 탭으로 자동으로 옮겨져요.
- **Claude에서 쓰던 여행 수첩**: 그쪽 앱에서 설정 → 백업 → **전체 복사** → 이 앱 홈에서 **백업 붙여넣기**
- **기기 바꿀 때**: 여행마다 설정 → 백업 → **파일로 저장** → 새 기기 홈에서 **백업 파일 불러오기**
  (공유 중인 여행은 새 기기에서 초대 링크로 다시 참여하면 돼요)

## 6. 수정한 뒤 반영하기

`index.html` 등을 고쳐 올렸다면 `sw.js` 맨 위의 `VERSION`을 `tripnote-v3`처럼 올려 주세요.
설치된 앱을 한 번 껐다 켜면 새 버전이 적용돼요. (`firebase-config.js`는 VERSION을 안 올려도 최신으로 받아요.)
